## 📊 Growth Pulse

> **Growth Pulse** is a front-end boilerplate project for dashboards and internal tools. It features tabs for analytics, user and employee tables, and an event calendar — all presented with clean UI components and smooth theming support.

---

### ✨ Features

* Analytics dashboard with charts
* User and employee management tables
* Event calendar with basic scheduling UI
* Light / Dark theme toggle
* Authentication powered by **Clerk**
* Static demo data (no backend integration)

---

### 🔧 Tech Stack

* **React** + **Vite**
* **Tailwind CSS** (custom styles)
* **Material UI** (components and theming)
* **MUI Charts** for visualizations
* **Clerk** for authentication
